# Three-File Delivery Quality Gate

Read this before generating or reviewing `01/02/03`.

## 01 Chief Editor Contract

Required sections:

- `先看结论`
- `主编只看`
- `来源锁定`
- `生成数量与选题规则`
- `平台发布矩阵`
- `来源与复刻证据`
- `主编审核`
- `合规与平台风险`
- `三文件一致性`
- `最终数量确认`
- `最终化条件`

Source evidence must distinguish:

| Type | Meaning | Counts as content fit? |
|---|---|---|
| 内容参考 | topic and claims match | yes |
| 结构参考 | hook, rhythm, order, or CTA only | no |
| 场景参考 | location, action, or Vlog atmosphere only | no |

Never turn `reference attached` into `100% fit`. A valid metric needs a denominator, a scoring rule, and item-level evidence.

## 02 Execution Contract

Required global sections:

- `执行团队只看`
- `执行团队审核`
- `拍摄与交付规范`
- `总拍摄发布表`
- `发布前检查`
- `发布后回收`

Each item needs:

- publish time and content type
- `来源关系` with separate content and structure references
- exact spoken text synchronized with `03`
- duration
- cover and platform title
- finished Douyin caption and pinned comment
- finished Xiaohongshu title and body
- topic-specific shot table
- privacy and compliance notes

The production specification should state at least:

- aspect ratio and framing
- audio check
- subtitle hierarchy and safe area
- cover output
- file naming and delivery owner
- how platform changes are reported back to the chief editor

The post-publish section should state what data is collected and when it is reviewed.

## 03 Speaker Contract

Required global sections:

- `余教授只看`
- `余教授本人审核`
- `表演规则`
- `不能说`

Each item contains only:

- title/id
- exact spoken paragraph
- short performance cue when useful
- optional pronunciation or pause cue

Do not include source links, heat, scoring, rewrite logic, shot directions, platform copy, or audit logs.

## Xiaohongshu Schemas

### Medical Main Video

Use complete sentences under:

`适合谁 / 先看什么 / 面诊前准备 / 避坑 / 收藏点 / 评论引导`.

The preparation must fit the exact topic. Do not paste `自然光照片 + 时间线` into every subject.

### Doctor-Life Or Production Vlog

Use complete sentences under:

`适合谁 / 观众能看到什么 / 拍摄观察点 / 隐私边界 / 收藏点 / 评论引导`.

Do not use `面诊前准备` unless the Vlog is genuinely about patient preparation.

## Natural Voice Checks

- Hooks may share a function but should not share identical syntax across most items.
- Category-only CTA can vary: vote, choose one, save a checklist, request the next topic, or name a problem type.
- Remove filler added only to satisfy duration.
- Read every Vlog aloud; repeated conclusion words such as `更稳 / 再稳一点 / 稳稳往前` signal padding.

## Shot Specificity Checks

For each explanatory beat, name the actual visual action:

- what is written, pointed to, compared, opened, covered, or moved
- which prop is used
- what the viewer learns from the action

`白板、模型、资料夹或手势任选` is not a final shot. It is an unresolved choice.

## Acceptance

The pack is ready for human review only when:

- all three files have the confirmed counts
- `02` and `03` spoken text is exact-match synchronized
- role purity is clean
- platform schemas match content type
- references are correctly classified
- generic shot placeholders are below the threshold
- duration, sensitive-claim, and delivery-quality scripts all pass

Human medical confirmation is still required before publication.
