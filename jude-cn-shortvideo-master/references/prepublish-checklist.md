# Pre-Publish Checklist

Use before handing content to an operator for posting. This skill never publishes automatically.

## 抖音

- 前三秒直接给冲突句，不寒暄。
- 标题和封面只讲一个判断。
- 字幕突出关键词，不遮挡脸和道具。
- 已加医疗边界小字。
- 置顶评论只收集问题类型，不做线上诊断。
- 无效果承诺、稀缺营销、患者背书和隐私画面。

## 小红书主视频

- 标题像用户会搜索的问题。
- 正文包含适合谁、先看什么、面诊前准备。
- 面诊前准备针对本条主题，不复制通用照片和时间线模板。
- 有收藏清单，不做成交导向。
- 避免焦虑化外貌评价。
- 评论引导只收集问题类型，不判断个人方案。
- 无私信导流、价格、预约暗示。

## 小红书 Vlog

- 标题明确这是医生日常、科普制作或场景观察。
- 正文包含适合谁、观众能看到什么、拍摄观察点、隐私边界。
- 内容复盘、拍摄道具和选题流程不写成面诊前准备。
- 只展示空白道具、脱敏空镜和类别词。
- 有可收藏的方法或观察点。
- 评论引导为主题投票或问题分类。
- 无私信导流、价格、预约暗示。

## 小红书非医疗主视频

- 标题明确这是内容复盘、制作方法或运营判断。
- 正文包含适合谁、先看什么、执行要点、避坑、收藏点、评论引导。
- 不为了套主视频模板强写面诊前准备。
- 执行要点包含可操作的时间、指标或步骤。
- 不展示后台账号、用户资料、私信或未公开数据。
- 评论引导只做主题投票，不延伸个人医疗判断。

## 微博

- 第一句是可转发观点。
- 正文控制在 120-220 字。
- 话题少而准。
- 保留观点但不攻击外貌或人群。
- 无广告化导流。

## 微信公众号

- 标题是科普问题，不是营销标题。
- 结构包含问题、误区、判断维度、准备清单、风险边界。
- 医学建议写清适用边界。
- 未确认事实标为待确认。
- 文末有非诊疗声明。
