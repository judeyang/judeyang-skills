# 镜头类型登记表

这份登记表用于在写 Prompt 前判断镜头生产策略。它不改变 `视频内容Prompt（含声音/负面）` 的三段式输出结构，也不要把 `L01/L02` 这类编号硬塞进模型-facing Prompt。登记编号只用于内部判断、Excel 辅助列、QC 和返工定位。

## 使用规则

1. 先读已确认脚本、资产、比例和目标工具，再给每个镜头选择一个主类型。
2. 一个镜头只写一个主类型；必要时在 `生成前执行说明` 里补充次要需求。
3. 类型只决定关键帧策略、参考素材角色和 QC 重点，不新增 Prompt 顶层标题。
4. 如果类型无法判断，标记 `待确认`，不要用泛化 Prompt 硬写。

## 类型库

| 类型 | 用途 | 首帧 | 中间关键帧 | 结尾帧 | QC 重点 |
|---|---|---|---|---|---|
| L01 情绪特写 | 表情、眼神、口型、反应 | 必需 | 默认跳过 | 变化明显才生成 | 脸、口型、眼神、台词完整 |
| L02 产品 Hero | 产品亮相、卖点露出、品牌识别 | 必需 | 产品状态变化才生成 | 常用 | Logo、结构、屏显、比例、手部遮挡 |
| L03 人物对话 | 两人或多人对话、视线关系 | 必需 | 默认跳过 | 走位或视线变化明显才生成 | 轴线、左右关系、台词、口型 |
| L04 动作推进 | 跑动、拿取、转身、进入/离开 | 必需 | 大位移或状态突变才生成 | 常用 | 动作连续、身体结构、终止状态 |
| L05 转场衔接 | 黑场、闪白、空镜过渡、节奏桥 | 看主体是否存在 | 不生成纯色关键帧 | 看下一镜需求 | 不把下一镜具体内容写进本镜头 |
| L06 空镜氛围 | 场景建立、环境情绪、天气空间 | 必需 | 默认跳过 | 通常跳过 | 空间、光线、时代、无文字水印 |
| L07 功能演示 | 产品功能、操作步骤、因果变化 | 必需 | 功能变化路径明显才生成 | 常用 | 操作路径、效果可见、产品不变形 |
| L08 特效卖点 | 气流、能量、魔法、转化、视觉化效果 | 必需 | 特效路径/峰值需要时生成 | 常用 | 特效不遮挡脸/手/产品/Logo |
| L09 群像调度 | 多人物位置、队形、集体反应 | 必需 | 走位复杂才生成 | 常用 | 人数、站位、视线、主体不丢失 |
| L10 结尾定格 | 口号、结果展示、收束画面 | 必需 | 默认跳过 | 必需或复用首帧 | 停留状态、后期字幕空间、不要生成字幕 |

## 类型到 Prompt 的映射

- `镜头任务：` 写清这个镜头要完成的叙事/产品任务，不写类型编号。
- `参考素材：` 只写实际存在或需要生成的文件角色；没有文件就写 `未提供实际文件` 或 `待生成`。
- `连续性：` 写角色位置、视线、产品状态、上一镜结束状态。
- `生成前执行说明` 写关键帧生成/跳过/复用理由，例如 `中间关键帧跳过：仅为细微表情变化，视频 Prompt 控制即可`。
- `视频内容Prompt（含声音/负面）` 仍然只使用 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三段。

## 反模式

- 不要为了“登记制”新增 `【镜头类型】`、`【镜头语言】`、`【导演说明】` 等顶层标题。
- 不要把所有镜头都归为产品 Hero 或情绪特写；类型必须服务当前镜头任务。
- 不要因为有中间动作就默认生成中间关键帧；只有物理位置、产品状态、特效路径或构图明显变化时才生成。
- 不要把类型登记当成创意文案；它是生产控制和 QC 工具。
