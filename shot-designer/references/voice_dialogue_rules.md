# Voice And Dialogue Delivery Rules

这份规则用于把 `台词/旁白` 写进视频生成 Prompt 时，让对白更像真人发声。它只记录可迁移的方法，不复制外部课程原文。

## Core Workflow

写 `声音：` 字段时按三步处理：

1. 锁定场景：写清人物所在环境、正在发生什么、为什么说这句话。
2. 锁定情绪：先判断这句台词是开心/兴奋、撒娇/亲近、警告/压迫、思考/犹豫、愤怒/质问、难过/委屈、紧张/害怕、怀疑/试探、安慰/温柔坚定、失望/心寒、舍不得/挽留、反派/掌控感、惊讶/不敢相信，还是中性叙述。
3. 锁定原文：先把 `台词/旁白` 原文完整放进 `声音：` 的 `{}` 中；不得漏字、改字、换词、压缩、摘要或只保留关键词。
4. 调整发声：优先在 `{原文}` 外写停顿、重音、气息、尾音等发声提示。只有用户明确允许“发声版标点增强”时，才可另写一个发声版台词；即便如此也必须同时保留原文。
5. 写发声提示：在 `声音：` 中同时给出台词文本和发声方式，例如音量、气息、速度、重音、尾音、停顿位置、情绪变化。

不能只写 `同期台词：xxx`。要让模型知道怎么说、哪里停、哪里轻、哪里重。

## Punctuation Effect Table

| 标点 | 主要作用 | 适合情绪 | 写法要点 |
|---|---|---|---|
| `，` | 制造自然短停顿 | 迟疑、解释、克制、转念 | 用在语义仍未结束的位置，让说话像边想边说；不要把整句切得过碎。 |
| `。` | 让语气收住 | 冷静、确定、失落、压低情绪 | 用在一句话真正落地的位置，让尾音停住；适合收束、决断、无力感。 |
| `！` | 加强重音和情绪 | 惊喜、命令、警告、爆发、兴奋 | 只放在需要重读或情绪上扬的位置；连续滥用会变成喊叫。 |
| `？` | 制造疑问、试探和不确定 | 怀疑、紧张、撒娇、反问、试探 | 让尾音轻微上扬；适合“不确定答案”的台词。 |
| `？！` | 质问、震惊、情绪爆发 | 愤怒、被冒犯、不可置信、追问 | 问号负责质问，感叹号负责冲击；用于句末，不要每句都用。 |
| `……` | 情绪卡住，不是普通停顿 | 难过、委屈、害怕、紧张、犹豫、舍不得、压抑 | 放在情绪断裂处；前半句压住，后半句更轻或更虚。 |
| `~` | 尾音轻快、柔软、亲近 | 开心、撒娇、轻松、温柔、亲密 | 用于尾音，不用于严肃、愤怒、恐惧、警告类台词。 |
| `--` | 情绪转折、突然改口或被打断 | 犹豫、惊觉、转念、打断、压住话 | 用于一句话内部的急转，不要当普通连接符使用。 |

## Emotion Combination Rules

| 情绪 | 标点组合 | 发声方向 | 适用场景 |
|---|---|---|---|
| 撒娇 | `？` + `~` + 少量 `，` | 音量偏轻，尾音柔软上扬，节奏略慢，语气亲近 | 亲密关系、请求、轻微抱怨、软化冲突。 |
| 警告 | 短句 + `。` / `！` | 声音压低，字更清楚，关键字重读，句尾收紧 | 危险提醒、命令、压迫感、上位者制止。 |
| 思考 | `，` + `……` + `？` | 前半句像在整理思路，中间有停顿，结尾带试探 | 推理、犹豫、临场判断、自言自语。 |
| 愤怒 | `？！` + `！` + 短句 | 起句压住，爆点突然加重，速度略快，尾部有冲击 | 质问、争吵、被欺骗、被挑衅。 |
| 难过 | `……` + `。` | 气息变弱，后半句更轻，句尾落下去 | 忍住眼泪、失望、委屈、告别。 |
| 开心 | `！` + `~` | 语速略快，声音明亮，尾音轻，关键字上扬 | 惊喜、轻松互动、获得好消息。 |
| 紧张 | `……` + `？` + 短停顿 | 声音发虚，停顿不稳，尾音上扬但没底气 | 害怕结果、等待判定、进入危险场景。 |
| 怀疑 | `？` + `？！` + 停顿 | 前半句压低或放慢，关键词重读，结尾带审视 | 识破谎言、试探对方、反问。 |
| 安慰 | `，` + `。` | 前半句放轻，后半句变稳，尾音稳稳落下 | 安抚、保护、陪伴、给安全感。 |
| 失望 | `。` + 慢节奏 | 声音变轻，尾音下沉，不哭喊不爆发 | 心寒、放弃争辩、突然明白真相。 |
| 舍不得 | `……` + `？` | 开口前停顿，声音很轻，尾音发虚 | 告别、挽留、不敢期待答案。 |
| 反派掌控 | `……` + `。` | 声音压低，语速很慢，尾音下压，轻微冷笑 | 等待猎物、权力压迫、掌控局面。 |
| 惊讶 | `……` + `？！` / `？` | 先停住，再抬高，尾音上扬 | 突然得知消息、不敢相信、意外收到东西。 |

## Voice Parameter Table

情绪不要只写名字，要拆成模型能执行的声音参数。

| 参数 | 可选方向 | 适用情绪 |
|---|---|---|
| 声音大小 | 放轻、压低、变亮、变弱、变稳 | 放轻适合难过/安慰/害怕/试探；压低适合愤怒/警告/怀疑/反派；变亮适合开心/惊喜；变稳适合安慰/坚定。 |
| 语速快慢 | 变慢、变快、一字一句、断断续续 | 变慢适合思考/难过/压迫/怀疑/安慰；变快适合开心/慌张/激动；一字一句适合质问/警告/失望；断续适合害怕/哭腔/舍不得。 |
| 呼吸状态 | 变浅、变重、带气声、不稳、先吸气再说 | 浅呼吸适合紧张/害怕/偷偷说话；重呼吸适合愤怒/压抑；气声适合温柔/亲密/难过；不稳适合委屈/舍不得。 |
| 停顿位置 | 开口前停、句中停、重点词前停、省略号停、逗号停 | 开口前停像犹豫；句中停像情绪卡住或思考；重点词前停制造压迫；省略号停适合难过/害怕/舍不得；逗号停适合思考/撒娇/安慰。 |
| 重音位置 | 前半句、后半句、关键词、最后几个字 | 前半句重读强调事实；后半句重读适合警告/质问；关键词重读强调信息；最后几个字重读制造压迫、怀疑或愤怒。 |
| 尾音变化 | 上扬、下压、发虚、放柔、拉长、稳稳落下 | 上扬适合疑问/试探/撒娇/怀疑；下压适合警告/反派/冷淡；发虚适合难过/害怕/舍不得；放柔适合安慰/亲近；拉长适合撒娇/轻快；稳落适合坚定/安全感。 |

## Scene Formula

台词提示词优先使用这个结构：

```text
人物在【场景】里，因为【原因/人物状态】情绪发生变化，声音【变轻/压低/变亮/变稳】，语速【变慢/变快/一字一句】，在【停顿位置】停顿，把【关键词】加重，尾音【发虚/上扬/下压/放柔/稳稳落下】地说：【台词】
```

更完整的分解结构：

```text
【场景】人物所在环境 + 正在发生的事情。
【人物状态】人物此刻的心理状态 + 为什么有这个情绪。
【发声方式】声音大小、语速快慢、呼吸状态、停顿位置、重音位置、尾音变化。
【台词】先完整保留原文；如允许发声版标点增强，原文和发声版必须同时存在。
```

## Example Transformations

示例只用于说明方法。写真实项目时，必须优先保留用户提供的原始台词含义和关键信息。

| 原始台词意图 | 更适合配音的写法 | 声音提示写法 |
|---|---|---|
| 不确定地询问对方是否会离开 | `你……真的要走吗？` | 声音放轻，`你` 后短暂停住，后半句尾音发虚，像不敢确认答案。 |
| 发现对方撒谎后的质问 | `你还说不是你？！` | 前半句压低，`不是你？！` 突然加重，带质问和爆发，不拖长。 |
| 开心地招呼对方 | `你终于来啦~` | 语速略快，声音明亮，尾音轻轻上扬，亲近但不过度撒娇。 |
| 冷静警告对方停下 | `别动。再往前一步，我就不客气了。` | 声音压低，两个句号都收住，`再往前一步` 放慢并重读。 |
| 边想边推理 | `等等……如果钥匙不在他手里，那会在哪里？` | 开头像突然想到问题，省略号后放慢，句尾带试探和思考。 |
| 强忍难过 | `没事……我早就习惯了。` | 前半句装作平静，中间停顿，后半句更轻，尾音落下。 |
| 安慰对方 | `没事的，我在这里。` | 前半句声音放轻，后半句更稳，尾音稳稳落下，像给对方安全感。 |
| 失望心寒 | `原来你一直都是这样想我的。` | 声音放轻，语速慢下来，不哭喊不爆发，尾音微微下沉。 |
| 反派掌控 | `你终于……来了。` | 声音压低，语速很慢，省略号停顿明显，尾音下压，带克制的轻蔑。 |
| 不敢相信 | `等一下……这是给我的吗？！` | 先愣住，前半句轻，后半句抬高，尾音上扬，带真实惊讶。 |

## Prompt Writing Rules

在 `【基础设定】` 的全局 `声音：` 中写边界：

```text
声音：只生成对白、同期环境声、动作音效、产品音效或房间底噪；台词按情绪使用自然停顿、重音、尾音和气息控制；不需要配乐，不生成BGM，音乐后期单独配。
```

在每个分镜的 `声音：` 中写具体台词和发声方式。`{}` 中必须优先放完整原文：

```text
声音：角色压低声音说{别动。再往前一步，我就不客气了。}，两个句号都收住，`再往前一步` 放慢重读；保留轻微衣料摩擦和脚步停住的同期声。
```

如果原文不能改，但需要表达停顿，不改 `{}` 中的台词，改写外部发声提示：

```text
声音：角色失望地说{原来你一直都是这样想我的。}；说出“原来”前先短暂停住，声音放轻，语速慢下来，尾音微微下沉，不哭喊、不爆发。
```

常用短句模板：

```text
温柔版：声音放轻，语速慢下来，尾音收得很柔，像在小心安抚对方地说：【台词】
坚定版：声音放稳，语速放慢，咬字清楚，尾音稳稳落下，像在给对方安全感地说：【台词】
愤怒版：声音压低，呼吸变重，语速放慢，咬字变重，像压着怒气一字一句地说：【台词】
害怕版：声音放轻，呼吸变浅，语速慢下来，中间停顿明显，尾音发虚地说：【台词】
怀疑版：声音压低一点，语速放慢，中间停顿，最后几个字微微上扬，像在试探对方地说：【台词】
开心版：声音变亮，语速稍微变快，尾音上扬，带着真实笑意地说：【台词】
难过版：声音很轻，语速慢下来，中间停顿明显，尾音发虚，像强忍情绪地说：【台词】
警告版：声音压低，语速放慢，后半句加重，尾音不要软掉，像最后一次警告地说：【台词】
```

## Boundaries

- 不得为没有台词的镜头硬加对白。
- 不得改变已确认台词的任何字词、顺序、数字、专有名词、事实含义、人物关系、产品卖点或法律/医疗/金融等敏感表述。
- 如果出现 `客户确认`、`一字不改`、`原文保留`、`不得修改`、`照抄`、`法务确认` 等要求，`{}` 中的台词必须逐字逐标点照抄；只能在 `{}` 外添加发声提示。
- 如果用户没有明确允许改写，默认不改台词文本，只改发声提示。
- 如果确实需要发声版标点增强，必须写成 `原文台词：{...}` + `发声提示：...` 或同时保留 `发声版：{...}`；不得用发声版替代原文。
- 情绪标点服务表演，不服务字幕。视频画面仍然默认不生成字幕、标题、角标或屏幕文字。
- 任何音乐、BGM、配乐只作为后期事项，不进入模型生成声音。
- 台词要匹配镜头时长；长句必须拆分时间段，或改为旁白后期处理。
