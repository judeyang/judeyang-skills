# 韦斯安德森交付检查清单

这份清单用于阶段结束前自检。它约束项目领航和交付纪律，不替代 `镜头设计师` 的 Prompt 标准。

## P0 · 阻塞交付

- 未确认脚本处理结论时，不得进入最终逐镜视频 Prompt。
- 未确认画幅/比例时，不得写最终首帧、结尾帧或视频 Prompt。
- 未提供官方产品图、Logo、屏显或品牌规则时，不得把 AI 生成产品图当成最终品牌参考。
- 未生成或确认 `04_最终确认归档/` 下的最终确认 PDF/HTML 时，不得进入 Phase 7 内部逐镜 Prompt。
- 客户确认文件不得暴露内部 Prompt、工具名、节点配置、成本结算或制作方法。
- 内部 Prompt 表不得放进 `02_用户确认文件/`。
- 任何已生成资产、样片或成片受客户修改影响时，必须先记录到 `02_用户确认文件/用户修改意见记录_vNN.xlsx` 或内部修改记录，再继续下游。

## P1 · 必须修正

- `脚本审核确认表` 和 `形象场景描述确认表` 必须是主确认 workbook 的前两个工作表。
- 客户确认表中短字段居中、长字段左对齐并自动换行。
- 所有 `待提供` / `待确认` / `预览/待确认` 状态必须具体说明缺什么和由谁补。
- 文件名必须递增版本号，不能覆盖旧版。
- 交付 PDF、HTML、Excel 版本号必须能互相对应。
- 目录只能使用项目白名单；新增目录必须来自用户明确指令。
- 阶段结束回复必须使用四行 Response Contract。

## P2 · 质量改进

- 开工前识别项目类型：产品广告、AI短剧、品牌片、口播知识片、电商种草片、其他。
- 根据项目类型调整确认重点，不要把所有项目套成同一张表。
- 对客户修改保留原话、反馈时间、影响镜头/资产、处理状态和下游影响。
- 对缺失素材使用 `待提供`，不要写成 `待补充` 或默认已拥有。
- 最终归档 PDF 只放客户需要确认/留档的内容，不放内部过程噪声。

## 项目类型到确认重点

| 类型 | 确认重点 |
|---|---|
| 产品广告 | 官方产品素材、Logo、屏显、卖点、产品出现方式、功能演示边界 |
| AI短剧 | 剧情逻辑、人物设定、台词时长、场景连续性、资产确认 |
| 品牌片 | 品牌口径、视觉气质、禁用表达、音乐/旁白授权、交付比例 |
| 口播知识片 | 文案事实、字幕策略、引用来源、讲解节奏、信息层级 |
| 电商种草片 | 平台比例、商品卖点、促销信息、手部/产品展示、字幕安全区 |
| 其他 | 先写明交付目标和验收标准，再进入目录和表格制作 |
